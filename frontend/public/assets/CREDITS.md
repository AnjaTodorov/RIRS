# Editorial assets

The Domora brand icon is supplied by the project owner in
`docs/img/Domora Sage Green House Icon.png`. `domora-logo.svg` embeds that
unchanged PNG in a tightly framed SVG viewport so it remains legible in
navigation and browser tabs. The original source file is preserved.

The architectural and interior images are brand/editorial illustrations only.
They are never used as substitute photographs for real property records.

- `architecture.webp`: https://images.unsplash.com/photo-1613490493576-7fde63acd811
- `interior.webp`: https://images.unsplash.com/photo-1600210492486-724fe5c67fb0
- Image license: https://unsplash.com/license
- Images are delivered locally as compressed WebP files.

DM Sans and DM Serif Display are distributed under the SIL Open Font License.
Their license notices are included in `fonts/OFL-DM-Sans.txt` and
`fonts/OFL-DM-Serif-Display.txt`. Fonts are served locally, including Slovenian
Latin Extended characters.
